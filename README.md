# Misrata Five-Platform Precipitation Analysis (2001–2025)
# تحليل الأمطار في مصراتة باستخدام خمسة منتجات مطرية (2001–2025)

**Prepared and Analyzed by: Dr. Badr Geo**  
**إعداد وتحليل:  بدر جيو**

## About the Project | نبذة عن المشروع

This project presents a comprehensive scientific analysis of precipitation over Misrata Airport, Libya, covering the period 2001–2025.

يقدم هذا المشروع تحليلًا علميًا شاملًا لبيانات الأمطار في مطار مصراتة، ليبيا، خلال الفترة 2001–2025.

## Precipitation Data Products | منتجات بيانات الأمطار

1. CHIRPS V3 SAT Daily
2. CHIRPS V3 RNL Daily
3. CHIRPS V3 Pentadal
4. NASA POWER Daily
5. ERA5-Land Daily UTC

## Study Area | منطقة الدراسة

- **Location:** Misrata Airport, Libya
- **الموقع:** مطار مصراتة، ليبيا

## Analysis Period | الفترة الزمنية

2001–2025 (25 years) | 25 سنة

## Scientific Analysis | التحليل العلمي

The project includes:

- Annual precipitation totals.
- Monthly precipitation totals and climatology.
- Pentadal precipitation analysis.
- Seasonal precipitation totals.
- Descriptive statistical analysis.
- Pairwise comparison between precipitation products.
- Data quality control and validation.
- Graphs, tables, and comparative results.

ويشمل المشروع:

- المجاميع السنوية للأمطار.
- المجاميع الشهرية والمناخية.
- تحليل الأمطار خلال الفترات الخماسية.
- المجاميع الموسمية.
- الإحصاءات الوصفية.
- المقارنات الإحصائية بين المنتجات المطرية.
- فحص جودة البيانات والتحقق منها.
- الرسوم البيانية والجداول والنتائج المقارنة.
